How it works

  1. In the game, open START > CO-OP > EDIT SPRITES. Your current look is saved in the game's sprites folder.
  2. Open that file here (or drag it onto this page) and paint, or use your own images.
  3. Press Save sprite sheet, then drag the saved file onto the game window. Your friends see it too.

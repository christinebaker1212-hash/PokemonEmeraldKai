Moemon Emerald Kai Co-op 1.62.3 "Faster Than a Hadoken!": the VS cabinets answer your buttons sooner.

The game installs this update by itself when it starts. Your save and settings stay as they are.
1.62.3 plays online with friends on 1.62.1 and 1.62.2 too.

## Fixed
- **Input lag on the VS cabinets.** While a fight is on screen the game no longer lets the picture fall behind
  your buttons: each frame is shown before the next one runs, so moves come out when you press them. This works
  with vsync on, as the game is set by default.
- **Online VS matches** no longer start with the biggest input delay when the arcade game takes a moment to load:
  it now follows your real connection, usually the smallest there is.

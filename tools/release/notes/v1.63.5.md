Moemon Emerald Kai Co-op 1.63.5 "Every File Its Own!": each save file keeps its own settings, and changing save files no longer restarts the game.

The game installs this update by itself when it starts. Your save and settings stay as they are.
1.63.5 plays online with friends on 1.63.0 to 1.63.4 too.

## Changed
- **Settings for each save file.** Your co-op settings (name, look, options), controls, display settings and server
  address now belong to the save file you play. Each save file starts with a copy of the settings you had, then
  keeps its own.
- **Changing save files on the title screen is instant.** SAVE FILE switches to the other file right away, without
  closing and opening the game again.

Moemon Emerald Kai Co-op 1.71.2 "Steady Link!": the phone link no longer closes the game, and shows the right ball.

The game installs this update by itself when it starts. Your save and settings stay as they are.

## MOEMON COMPANION
- **No more closing:** an evolution started from the phone now begins the way a trade's does in the game (the screen
  fades, then the evolution), which could close the game before. If something the phone asked for ever closes the
  game again, it's never tried again on the next link: the phone lists it under COULDN'T DO.
- **The right ball:** each POKéMON shows the ball it's really in, special balls too (it showed a MASTER BALL for a
  POKé BALL).
- **SPAWNS opens on the region you're in,** with HOENN, JOHTO, KANTO and SINNOH to switch between.
- If the game is older than the app, the app says so (restart the game and it updates itself).
- A rare POKéMON's colors no longer risk closing the game when the phone links.

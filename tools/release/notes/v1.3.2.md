Moemon Emerald Kai Co-op 1.3.2: MoeGatcha no longer crashes on ROUTE 111.

The game installs this update by itself when it starts. Your save and settings stay as they are.

## Fixed
- **Opening MoeGatcha crashed the game on ROUTE 111 while the MIRAGE TOWER was showing.** The tower's shimmer kept
  running for a moment after the screen started closing the field, with its data already gone. Older versions had
  the same problem; it only shows up on ROUTE 111 when the tower is there. Any screen that closes the field this way
  is now safe too.

Moemon Emerald Kai Co-op 1.190.4 "Same Letters!": the MOéDEX's FIND menu and MORE pages use the game's own lettering, and FIND slides up and away like the START menu.

The game installs this update by itself when it starts. Your save and settings stay as they are.

## The MOéDEX
- FIND (LT, or F on the keyboard) is written in the same letters as the START menu, at the same size, and it
  slides up from the bottom and back down as that menu does. Before, it used smaller letters and just appeared.
- MORE on an entry (R) is written in the letters the entry itself uses.
- The labels beside the L, R and LT buttons on the list use the game's own letters too.

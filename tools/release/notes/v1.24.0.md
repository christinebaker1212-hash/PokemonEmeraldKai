Moemon Emerald Kai Co-op 1.24.0 "Pockets for Everything!": a new BAG with eight pockets and FAVORITES, item descriptions from DIAMOND, PEARL, PLATINUM, HEARTGOLD and SOULSILVER, and REJOIN without the invite code.

The game installs this update by itself when it starts. Your save and settings stay as they are.
1.24.0 plays online with friends on 1.23.0 too.

## New
- A new BAG screen: the pocket icons in a row, the pocket's name under them, a bigger list with a red frame on the
  item you're on, and the item's picture and description along the bottom. BRENDAN's and MAY's bags are still there.
- Eight pockets, in this order:
  - ITEMS
  - MEDICINE: everything that heals, cures, restores PP or raises levels.
  - POKE BALLS
  - TMs & HMs
  - BERRIES
  - BATTLE ITEMS: X ATTACK, GUARD SPEC. and the others used only in battle.
  - KEY ITEMS
  - FAVORITES: any items you like, from every pocket.
- LEFT / RIGHT (or L / R) go straight to the next pocket, round and round.
- FAVORITE in an item's menu puts it in FAVORITES as well (as many items as you like); UNFAVORITE takes it out again.
- The BAG has room for every kind of item at once, still up to 999 of each.
- START still sorts a pocket. ITEMS, MEDICINE and BATTLE ITEMS share one order, and moving an item with SELECT works
  in each of them.
- Every item's description is now the one from HEARTGOLD and SOULSILVER (or PLATINUM, DIAMOND and PEARL), TMs and
  HMs included. Items those games don't have keep theirs. Where a description doesn't fit a small box (a POKE MART,
  the PC's item storage), it shows a part at a time and moves on by itself.
- REJOIN on the CO-OP screen now gets you back into a friend's game you joined with an invite code: no code or
  password to type again. ENTER CODE OR IP starts with the last code you used, too.

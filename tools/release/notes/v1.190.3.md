Moemon Emerald Kai Co-op 1.190.3 "As It Always Was!": the MOéDEX's new parts now look and work like the MOéDEX itself, and SELECT is SEARCH again.

The game installs this update by itself when it starts. Your save and settings stay as they are.

## The MOéDEX
- SELECT opens SEARCH, as it always did. Nothing the MOéDEX had has moved or gone.
- The title is back at the top of the list. The new buttons sit beside START and SELECT and are drawn the way
  those are: L for REGION or NATIONAL, R for OWN or SHARED, and LT (F on the keyboard) for FIND.
- FIND is a menu like the one START opens: the same blue box, the same letters, the same arrow. It holds
  JUMP TO, ORDER, SHOW, GENERATION, TYPE, ABILITY, MOVE and EGG GROUP. LT or B closes it.
- SHOW (ALL, NOT SEEN, NOT CAUGHT, CAUGHT, FRIENDS') is a row of FIND now, with the rest of what narrows the
  list. The button beside the list says FIND ON while anything is narrowing it.
- How much you have caught is a thin line along the bottom of the picture's frame: gold for your own, blue
  for what friends added.
- MORE on an entry (R) is drawn as the entry's own card: pale, with dark letters.

Moemon Emerald Kai Co-op 1.204.4 "Ball Page Makeover!": the POKé BALL page in RED, CRYSTAL and FIRERED is laid out like each game's own pages, and Game Boy letters never turn into "?".

UI STYLE
- POKé BALL page: in RED, CRYSTAL and FIRERED it now uses the style's own INFO page, with the POKéMON's picture and details on top and the ball, its COLOR, DECOR and EFFECT set out in the page's own boxes and tags. Changing the ball shows the buttons the way each game shows them, and the "use a ball?" question appears in RED's and CRYSTAL's message box or FIRERED's BALL MEMO.
- RED / CRYSTAL: every letter the game uses now has a Game Boy look: accented letters, arrows, < >, quotes, $ and the PK MN symbols no longer show as "?".
- Button prompts written as letters keep a space after the button ("A OK", not "AOK"), and the d-pad's prompts show arrows in every style.
- RED / CRYSTAL: JOURNAL entries break onto new lines as they should.
- FIRERED: the summary's top banner keeps the same place and length on the last page.
- Button icons always keep their true colors, in LIGHT or DARK, whatever the screen around them is doing.

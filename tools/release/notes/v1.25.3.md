Moemon Emerald Kai Co-op 1.25.3 "Castform Changes Safely!": CASTFORM no longer crashes battles when the weather changes it.

The game installs this update by itself when it starts. Your save and settings stay as they are.
1.25.3 plays online with friends on 1.25.0, 1.25.1 and 1.25.2 too.

## Fixed
- A foe's CASTFORM could crash the game in battle when it changed form in rain, sunshine or hail. It now changes into
  its weather form as it should.
